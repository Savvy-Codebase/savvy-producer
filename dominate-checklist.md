# Savvy Leads — Dominate Checklist

Order matters. Phase 0 unblocks everything. Phase 1 closes the trust gap. Phases 2–5 are the new products. Items marked **[GATE]** must be done before the thing they gate goes live.

## Phase 8 — Compliance review and agent-facing explanation

This phase becomes a public section agents read before buying. It must explain three things. Every statement in it has to be true of how Savvy's leads are actually collected, so counsel reviews it before it goes live. **[GATE]** for the sales bot and for any "safe to call and text" wording.

**8a. Jornaya LeadiD, in plain terms**
- [ ] Explain what a LeadiD is and what it proves: an ID created when the consumer loads the form, tied to a recorded session showing the consent language they saw and when they submitted it.
- [ ] Show a sample certificate (redacted) and where the agent can look one up.
- [ ] State which lead tiers carry a LeadiD or TrustedForm certificate. The public site currently shows them only for real-time leads. If territory and overflow leads don't carry one, say so or fix it first.
- [ ] Say how long certificates are retained and how an agent requests one for a specific lead.

**8b. Exclusivity**
- [ ] Define it in writing: sold to one buyer per lead, per product, and whether a lead is ever resold after a window (overflow is "sold once"; territory leads go to the reserving agent first).
- [ ] Make the consent language match. The disclosure the consumer saw must name who may contact them. If the language names several sellers, the lead is not exclusive and the site can't say so.
- [ ] State how Savvy enforces it (suppression across buyers, de-duplication) and what the remedy is if a duplicate is found. This links to the bad-lead policy in Phase 1.

**8c. Why it is safe for agents to call and text**
- [ ] Don't publish "safe" as an unqualified claim. Publish the specific facts that support it: the consent language and its date, who it names, the certificate, DNC scrub status, and which numbers were checked and when.
- [ ] Explain what the agent still has to do on their side: honor opt-outs, calling hours, state rules, their own DNC scrub, and texting rules (consent covers texts only if the language says texts).
- [ ] Have counsel confirm the consent language supports the claims on this page.
- [ ] Add an indemnity or warranty position if Savvy will give one, and state its limits. Decide this with counsel, not in marketing copy.

**8d. General review**
- [ ] Have counsel review the TCPA page and the consent language. Calling with an A.I. voice counts as an artificial voice under the TCPA per the FCC's 2024 ruling, so it needs prior express written consent. Confirm this applies to Savvy's use.
- [ ] DNC scrubbing in the call flow, and state calling-hour rules.
- [ ] Recording disclosure in the greeting for calls and a notice in chat.
- [ ] Review all marketing claims ("exclusive", "compliant", any production numbers) against what can be shown.
